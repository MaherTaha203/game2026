# ONE LINE — Quality Gates

A phase cannot be declared complete merely because implementation exists.

## Gate 1 — Repository

* Repository understood.
* Git state understood.
* No unrelated work destroyed.

## Gate 2 — Core Engine

* Puzzle rules implemented.
* Core tests pass.

## Gate 3 — Levels

* Level schema validated.
* All production levels validated.
* All production levels solved.

## Gate 4 — Gameplay

* Runtime accepts valid solutions.
* Invalid actions handled.
* Restart works.
* Completion works.

## Gate 5 — Progression

* Unlocking works.
* Stars work.
* Save/load works.

## Gate 6 — Persistence

* Corruption handled.
* Migration tested.
* Reset works.

## Gate 7 — Polish

* UI coherent.
* Animations functional.
* Audio functional where implemented.
* Input responsive.

## Gate 8 — Mobile

* Responsive layout.
* Safe areas.
* Touch behavior.
* Lifecycle behavior.

## Gate 9 — Security/Privacy

* No secrets.
* No unnecessary permissions.
* No unauthorized network behavior.

## Gate 10 — Release

* Release configuration exists.
* Version/build metadata exists.
* Store assets prepared.
* Documentation complete.

## Gate 11 — Final Audit

No unresolved release-blocking FAIL.

All remaining UNVERIFIED/HUMAN ACTION REQUIRED items explicitly documented.
