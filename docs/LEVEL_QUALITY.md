# ONE LINE — Level Quality Standard

A level must satisfy both correctness and quality requirements.

## Correctness

* Valid structure.
* Valid references.
* Connected where required.
* Solvable.
* Runtime playable.
* No unintended rule violation.

## Quality

Evaluate:

* difficulty;
* uniqueness;
* solution length;
* branching;
* ambiguity;
* progression placement;
* visual readability;
* accidental triviality.

## Difficulty Distribution

The final collection should contain a deliberate progression.

Do not simply generate 200 random puzzles and call them a campaign.

## Duplicate Control

Detect exact and substantial duplicates.

## Determinism

Record:

* generator version;
* seed;
* configuration.

A production level should be reproducible.

## Acceptance

Candidate → Validation → Quality Analysis → Curation → Production

Only production-approved levels belong in the release collection.
