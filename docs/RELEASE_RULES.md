# ONE LINE — Release Rules

## Release Candidate Requirements

The release candidate must have:

* fixed application version;
* fixed build number;
* known Git commit;
* validated production levels;
* passing automated tests;
* passing regression suite;
* verified save system;
* documented known issues;
* store assets;
* privacy documentation;
* release notes.

## External Requirements

The project owner may need to perform:

* developer-account configuration;
* signing;
* certificate management;
* provisioning;
* store upload;
* store metadata submission;
* real-device testing;
* store review actions.

These are HUMAN ACTION REQUIRED unless actually completed.

## No Fake Credentials

Never generate fake production credentials.

## Store Verification

Current Apple and Google requirements must be checked against official documentation at the time of submission.

Do not assume historical requirements remain current.

## Publication

"Release-ready" and "published" are different statuses.

The game is not considered published merely because a release build exists.
