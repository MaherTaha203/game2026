# ONE LINE — Definition of Done

A feature is DONE only when:

* implementation exists;
* intended behavior is documented;
* automated tests exist where appropriate;
* relevant tests pass;
* integration is verified;
* regressions are checked;
* documentation is updated where necessary;
* known limitations are recorded.

## A Level Is DONE When

* structurally valid;
* solvable;
* runtime playable;
* quality checked;
* correctly categorized;
* included in the intended progression.

## A Build Is DONE When

* it builds successfully;
* correct project configuration is used;
* version/build metadata is correct;
* no known release-blocking issue exists.

## The Game Is DONE When

* the core game is complete;
* intended level collection is complete;
* progression works;
* save system works;
* automated tests pass;
* level solver/playtester passes;
* release build is verified as far as the environment permits;
* documentation is complete;
* remaining external human actions are explicitly listed.

## Important

Claude saying "complete" is not evidence of completion.

The evidence determines status.
